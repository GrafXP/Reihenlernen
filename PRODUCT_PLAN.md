# Reihen-Mission

## Scope

A calm multiplication trainer based on the Blitzrechnen template. The ten available rows are 2–9, 11 and 12. Each row includes factors 1–12. The interface uses Swiss Standard German.

## Learning journey

1. Select one or more rows on the home screen.
2. Explore a row with the learning view: all twelve equations, hidden-result recall, dot arrays and anchor strategies.
3. Select a reward and a mission setting, then practise the selected rows.
4. Receive ten points per resolved task, with help available at any time.
5. Collect the reward and start a fresh round. Parent PIN protection controls redemption and settings.

The scheduler prioritises facts without independent evidence and distributes mixed rounds across the selected rows. Products, missing factors and sequences connect recall with understanding. Mastery requires all twelve facts independently solved; assistance counts as practice without falsely claiming independent mastery. This is an on-device practice indicator, not a school assessment.

## Template foundations

Responsive React/TypeScript app, local IndexedDB storage, reward catalogue and collection, parent PIN, three cosmetic mission settings, supportive parent insight, optional speech and sound, contrast and motion settings, offline service worker, installable PWA.
